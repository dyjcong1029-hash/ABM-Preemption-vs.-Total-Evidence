# ABM-Preemption-vs.-Total-Evidence
This repository contains NetLogo agent-based models comparing total evidence and preemption strategies in epistemic deference.

## Models

- Version 1: Learning the expert's evidence
- Version 1.1: Weighted update rule
- Version 2: Learning the expert's credence
- Version 3: Inheriting the expert's alpha and beta parameters

## Structure

- `models/`: NetLogo model files
- `data/`: BehaviorSpace output
- `code/`: R scripts for data analysis
- `figures/`: plots and visualizations
