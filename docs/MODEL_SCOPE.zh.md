# 当前模型的范围与验收标准

本工作副本以 GitHub `dyjcong1029-hash/ABM-Preemption-vs.-Total-Evidence` 的提交 `e105f6217db78222e72633a663871c070d630ed3` 为准。`source_manifest.json` 保存该版本37个发布文件的 Git blob SHA。本轮的目标是把现有基线做到可检查、可运行、可复现，保持原来的科学问题、三个实验、主体规则、随机种子和默认参数。

## 1. 科学设定

- 真实世界只有两种：A成功率恒为0.50，B为0.55或0.45。主体不知道当前世界。当前版本不是两臂连续未知成功率的Beta模型。
- 一位专家与十位学生使用相同先验、逐结果似然更新和Thompson选臂规则。专家前25轮有125次研究机会；每位学生每轮实验一次，并接收左右邻居的第一手结果。
- 消息延迟一轮，不转发他人的消息。证据身份相同的记录只能计一次；在给定世界和选臂后，新实验使用独立的环境随机结果。
- 第25轮结果和邻居消息全部处理后、下一轮行动前进行一次教师广播。前史正常共享时，每名学生拥有75条本地记录，其中只有B结果区分世界。
- 实验0不接收教师意见；实验1接收125条原始教师记录；实验2只接收教师置信度所在的十分位区间及其预先冻结的报告语义。
- P在干预时排除旧本地证据的决策贡献，TE保留该贡献并加入教师输入。P的旧记录仍用于审计和去重。P和TE在此后都继续吸收新实验与邻居证据。

## 2. 概率、行动与评价必须分开

`q=P(B-good|E)`表示B更好的信念。B下一次成功的预测概率为`0.45+0.10q`，Thompson选择B的概率为`q`。真实成功率、后验信念和行动概率不能混用。

对数赔率`L=ln(q/(1-q))`初值为0。B成功增加`ln(11/9)`，失败减少同一数值；A的成败更新量为0。原始证据合并使用去重后的似然贡献；实验2使用`ln[P(报告|B-good)/P(报告|B-bad)]`，不能直接把报告区间中点当成更新后的信念。

主要指标是第26—500轮的累计期望后悔值。每次选错增加0.05，偶然一次成功或失败不会改变该轮的期望后悔值。最终Brier、真实世界概率、早期与末期行动表现是不同指标，不应替代或混称。

配对比较的独立统计单位是完整的“世界×随机种子”运行。同一运行内的十位学生和各轮状态相关，不能当成独立重复。置信区间描述模拟重复的有限抽样误差，不是现实学生群体的抽样区间。

原分析的恢复指标也须分开：实验1使用20轮窗口的平均正确选择率达到60%，报告已恢复运行的中位数并另外保存删失比例；实验2要求连续20轮的每一轮均达到60%，未恢复运行使用受限延迟476。它们不是同一个估计对象，不能直接拿恢复时间作跨实验排名。实验1公开说明中引用的错误教师轨迹样本均在期限内恢复；这不意味着任意新增运行都不会删失。

## 3. 有限推理与结论边界

主体对收到的实验成败作局部贝叶斯似然更新。它没有从邻居为何选择A或B反推出其不可见证据。因此，这个更新规则不能自动解释为“利用全部可见社会信息后的完整贝叶斯后验”，也不能称为贝叶斯最优行动规则。Thompson sampling是本模型的具体行动算法。

教师报告的条件分布在独立校准与验证后冻结，学生在正式运行中知道这套语义。当前模型不包含学生学习教师信誉、不同推理能力、错误似然、策略性欺骗或认知处理成本。

P与TE的比较是当前一次性证据基础替换规则的比较，不能泛化为所有哲学版本的preemption。现有结论是在有效、独立、正确解释的信息条件下，保留旧证据如何影响有限期行动损失。TE与P在动态Thompson下的累计后悔值比较，必须由实际运行检验，不能直接套用单次平方误差的信息优势公式。

## 4. 验收门槛

1. 三个`.nlogox`的嵌入代码与对应`.nls`一致；核心科学文件与固定上游Git blob一致。
2. 数学例子、概率变换、消息似然语义和正式实验网格通过可重跑检查。
3. 从公开原始端点重新构造配对差值、均值与原方法的统计区间，并与发布表比较。
4. 真正启动原生NetLogo，检查运行网格、结束时点、实验计数、消息和证据恒等式；只凭Java退出码不能宣告通过。
5. 用逐轮轨迹检验No-Deference跨实验一致性和精确报告回归；特殊的负例与不透明信息隔离检查须单独记录实际覆盖。
6. 从完整原始轨迹恢复校准、分析、图表和恢复时间。聚合学习曲线不能替代个体轨迹重算恢复时间。
7. 所有新增结果写入新目录，记录源文件与输入哈希；原始发布数据不被覆盖。

验收报告必须区分数学检查、静态源码审查、少量原生回归和完整批量重跑。有限检查通过只表示已检查范围内没有已知阻断问题，不构成对所有未来输入或现实课堂的保证。
